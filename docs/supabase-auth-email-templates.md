# Supabase Auth email templates

Use these templates in **Supabase Dashboard → Authentication → Email Templates** for the Teachfolio project. Set each template's subject as shown. Replace the template HTML with the matching block. The links use Supabase's `{{ .ConfirmationURL }}` value so confirmation, recovery, and invitation tokens remain generated and validated by Supabase Auth.

Use the staging project first, and verify the sender domain and allowed redirect URLs before sending to real users. Keep the existing SMTP sender address consistent with `RESEND_FROM_EMAIL`.

## Shared visual style

The templates use Teachfolio's blue `#285bc0`, a white content card, simple typography, and a single clear action. They are intentionally table-based and inline-styled for email-client compatibility. The header loads the existing `/teachfolio-mark.svg` from the Supabase `{{ .SiteURL }}` and keeps the Teachfolio wordmark beside it as a readable fallback. Set Supabase's Site URL to the public app origin and ensure that URL serves the mark publicly over HTTPS. Some email clients block remote images; in those clients the wordmark remains visible. Each email includes a plain URL fallback and a short explanation if the recipient did not request the action.
